# Задание на программирование 8

**Дисциплина** Программирование на Java. Создание современных веб-приложений

**Тема** Работа с файлами и потоками

## Задание 1: Чтение данных из файла и вывод в консоль

Создайте программу, которая читает текстовый файл и выводит его содержимое в консоль. Программа должна:
- Прочитать файл `input.txt`, который находится в корне проекта.
- Вывести каждую строку файла в консоль.
- Обработать исключения, связанные с отсутствием файла или ошибками при чтении.

**Требования**
- Используйте классы `FileReader` и `BufferedReader` для чтения файла построчно.
- Реализуйте корректное закрытие потока с использованием `try-with-resources`.
- Обработайте исключения с помощью `catch` блока и выведите сообщение об ошибке в консоль.

**Пример вывода в консоль**
```
Строка 1: Привет, мир!
Строка 2: Это файл input.txt
Строка 3: Конец файла.
```

## Задание 2: Запись данных в файл

Создайте программу, которая записывает данные в текстовый файл. Программа должна:
- Создать файл `output.txt` в корне проекта.
- Записать в файл строки от "Запись 1" до "Запись 10".
- Добавить в конец файла строку "Файл успешно записан".

**Требования**
- Используйте классы `FileWriter` и `BufferedWriter` для записи в файл.
- Реализуйте корректное закрытие потоков с использованием `try-with-resources`.
- Проверьте, что файл успешно создан и записан.

**Пример вывода в консоль**
```
Данные успешно записаны в файл output.txt
```

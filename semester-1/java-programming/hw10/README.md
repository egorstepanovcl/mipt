# Задание на программирование 10

**Дисциплина** Программирование на Java. Создание современных веб-приложений

**Тема** Реализация клиент-серверного взаимодействия

Вам необходимо создать программу, которая использует возможности Java NIO (Nonblocking I/O) для реализации клиент-серверного взаимодействия. Программа будет использовать каналы и буферы для асинхронной работы с данными в сети. Задание состоит из двух частей:

1. Реализовать сервер, который будет ожидать подключений от клиентов и отправлять данные.
2. Реализовать клиента, который подключается к серверу и получает данные.

Сетевое взаимодействие должно быть выполнено с использованием NIO, без использования традиционных блокирующих сокетов.

## Часть 1: Реализация сервера

1. Создайте сервер, который будет слушать на порту 5050 и принимать подключения от клиентов.
2. Используйте класс `ServerSocketChannel` для прослушивания порта.
3. Используйте класс `SocketChannel` для принятия соединений от клиентов.
4. Сервер должен отправлять строку "Hello from the server!" клиенту, который подключается.
5. Ответ должен быть отправлен через канал, используя класс `ByteBuffer` для упаковки данных перед отправкой.
6. Сервер должен обрабатывать несколько клиентов одновременно, используя неблокирующие каналы и селекторы для асинхронной обработки соединений.
7. Сервер должен быть способен отправлять данные в ответ на подключение клиента.

## Часть 2: Реализация клиента

1. Создайте клиент, который будет подключаться к серверу на порт 5050.
2. Клиент должен отправлять запрос на сервер (например, просто подключение) и получать строку "Hello from the server!" в ответ.
3. Используйте класс `SocketChannel` для установления соединения с сервером.
4. Клиент должен использовать `ByteBuffer` для получения данных от сервера.
5. Клиент должен вывести полученные данные на экран.

## Часть 3: Асинхронность и многозадачность

1. Сервер должен поддерживать одновременные подключения нескольких клиентов, используя `Selector` для асинхронной обработки подключений и сообщений.
2. Сервер должен использовать метод `select()` для обработки событий на каналах, таких как готовность канала для чтения или записи.
3. Сервер должен обрабатывать соединения, получать данные от клиентов и отправлять ответы без блокировки выполнения.

## Часть 4: Обработка ошибок

1. Обрабатывайте ошибки, связанные с подключением и передачей данных (например, `IOException`).
2. При возникновении ошибок выводите сообщение об ошибке в консоль.

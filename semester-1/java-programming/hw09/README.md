**Дисциплина** Программирование на Java. Создание современных веб-приложений

**Тема** Введение в многопоточность

## Задание 1: Создание и запуск потоков в Java

Создайте программу, которая запускает несколько потоков для выполнения различных задач. Программа должна:
1. Реализовать два потока: один, который будет считать числа от 1 до 10, и другой — от 11 до 20.
2. Каждое число должно быть выведено в консоль с интервалом в 1 секунду.
3. Потоки должны быть запущены одновременно.
4. Выведите в консоль информацию о том, какой поток выполняет текущую задачу.

**Требования**

1. Реализуйте класс `NumberPrinter`, который будет реализовывать интерфейс `Runnable` и выводить числа с интервалом в 1 секунду.
2. Создайте класс `Main`, который будет запускать два потока.
3. Используйте метод `Thread.sleep(1000)` для создания паузы между выводами чисел.
4. Реализуйте корректный запуск потоков и их завершение.

**Пример вывода в консоль**
```
Поток 1: 1
Поток 1: 2
...
Поток 2: 11
Поток 2: 12
```

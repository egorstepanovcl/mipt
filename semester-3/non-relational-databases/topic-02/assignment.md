# Описание

## 1. Подготовка базы данных

Выполните в консоли:

```javascript
use school_db

db.students.insertMany([
  {
    name: "Анна",
    age: 20,
    course: 1,
    subjects: ["математика", "физика"],
    GPA: 4.5
  },
  {
    name: "Иван",
    age: 22,
    course: 3,
    subjects: ["информатика", "математика"],
    GPA: 4.2
  },
  {
    name: "Мария",
    age: 19,
    course: 1,
    subjects: ["литература", "история"],
    GPA: 4.8
  },
  {
    name: "Петр",
    age: 21,
    course: 2,
    subjects: ["физика", "химия"],
    GPA: 3.9
  },
  {
    name: "Елена",
    age: 20,
    course: 2,
    subjects: ["биология", "химия"],
    GPA: 4.1
  }
])
```

## Задание 1. Знакомство с коллекцией

Посмотрите все документы в коллекции `students` в красивом формате.

### Чек-лист действий

* [ ] Использован метод `find()`.
* [ ] Добавлен метод `.pretty()` для красивого вывода.
* [ ] Видны все 5 документов.

## Задание 2. Поиск по условию

Найдите всех студентов первого курса.

### Чек-лист действий

* [ ] Использован фильтр `{ course: 1 }`.
* [ ] Получено 2 документа: Анна и Мария.
* [ ] У всех найденных студентов `course = 1`.

## Задание 3. Сложный фильтр

Найдите студентов, у которых средний балл выше `4.0` и возраст младше `21` года.

### Чек-лист действий

* [ ] Использован оператор `$gt` для `GPA`.
* [ ] Использован оператор `$lt` для `age`.
* [ ] Получено 2 документа: Анна и Елена.
* [ ] Все результаты соответствуют заданным условиям.

## Задание 4. Обновление документа

Повысьте средний балл Марии на `0.2` балла.

### Чек-лист действий

* [ ] Использован `updateOne()` для обновления одного документа.
* [ ] Использован оператор `$inc` для увеличения `GPA`.
* [ ] Проверено, что `GPA` Марии теперь равен `5.0`.
* [ ] Остальные данные не изменились.

# Команды для самопроверки

## Задание 1

```javascript
db.students.find().pretty()
```

## Задание 2

```javascript
db.students.find({ course: 1 })
```

## Задание 3

```javascript
db.students.find({
  GPA: { $gt: 4.0 },
  age: { $lt: 21 }
})
```

## Задание 4

```javascript
// Обновление
db.students.updateOne(
  { name: "Мария" },
  { $inc: { GPA: 0.2 } }
)

// Проверка
db.students.find({ name: "Мария" })
```

# Советы по самопроверке

* Если не получается найти документы — проверьте, что вы находитесь в нужной базе данных:

```javascript

```

Результатом должно быть:

```text
school_db
```

* Если команда не работает — проверьте синтаксис: запятые, скобки и кавычки.
* Если после обновления не видно изменений — выполните запрос на поиск ещё раз.

# Самостоятельное задание по теме 2

**Дисциплина:** Нереляционные базы данных

**Тема:** Документоориентированные базы данных на примере MongoDB

## Цель работы

Закрепить навыки выполнения базовых CRUD-операций и простых запросов в MongoDB с использованием консоли `mongosh`.

---

## 1. Подготовка базы данных

Для выполнения задания была создана база данных `school_db`.

```javascript
use school_db
```

Проверка текущей базы данных:

```javascript
db
```

Результат:

```text
school_db
```

В коллекцию `students` были добавлены пять документов:

```javascript
db.students.insertMany([
  { name: "Анна", age: 20, course: 1, subjects: ["математика", "физика"], GPA: 4.5 },
  { name: "Иван", age: 22, course: 3, subjects: ["информатика", "математика"], GPA: 4.2 },
  { name: "Мария", age: 19, course: 1, subjects: ["литература", "история"], GPA: 4.8 },
  { name: "Петр", age: 21, course: 2, subjects: ["физика", "химия"], GPA: 3.9 },
  { name: "Елена", age: 20, course: 2, subjects: ["биология", "химия"], GPA: 4.1 }
])
```

Для проверки количества документов выполнена команда:

```javascript
db.students.countDocuments()
```

Результат:

```text
5
```

Таким образом, база данных и исходная коллекция были успешно подготовлены.

### Результат

Все 5 документов коллекции успешно выведены с использованием методов `find()` и `.pretty()`.

## 4. Задание 3. Сложный фильтр

Необходимо найти студентов, у которых:

- `GPA > 4.0`;
- `age < 21`.

Выполнен запрос:

```javascript
db.students.find({
  GPA: { $gt: 4.0 },
  age: { $lt: 21 }
}).pretty()
```

Получены следующие документы:

```text
Анна  — age: 20, GPA: 4.5
Мария — age: 19, GPA: 4.8
Елена — age: 20, GPA: 4.1
```

Количество найденных документов дополнительно проверено командой:

```javascript
db.students.countDocuments({
  GPA: { $gt: 4.0 },
  age: { $lt: 21 }
})
```

Результат:

```text
3
```

### Результат

Условиям запроса соответствуют **3 студента: Анна, Мария и Елена**.

> **Примечание:** в чек-листе исходного задания указано, что должны быть найдены только 2 документа — Анна и Елена. Однако Мария также удовлетворяет обоим условиям, поскольку её `GPA = 4.8 > 4.0`, а `age = 19 < 21`. Поэтому фактический результат MongoDB из трёх документов является корректным.

---

## 5. Задание 4. Обновление документа

Необходимо повысить средний балл Марии на `0.2`.

Перед изменением был проверен документ Марии:

```javascript
db.students.findOne({ name: "Мария" })
```

Исходное значение:

```text
GPA: 4.8
```

Для обновления документа выполнена команда:

```javascript
db.students.updateOne(
  { name: "Мария" },
  { $inc: { GPA: 0.2 } }
)
```

MongoDB сообщил об успешном обновлении:

```text
matchedCount: 1
modifiedCount: 1
```

После этого выполнена проверка:

```javascript
db.students.findOne({ name: "Мария" })
```

Результат:

```text
name: Мария
age: 19
course: 1
subjects: [литература, история]
GPA: 5
```

Также документ был выведен в формате `pretty()`:

```javascript
db.students.find({ name: "Мария" }).pretty()
```

### Результат

Средний балл Марии успешно увеличен с `4.8` до `5.0`. Остальные поля документа не изменились.

## 8. Удаление студента с минимальным GPA

Сначала был найден студент с наименьшим средним баллом:

```javascript
db.students.find().sort({ GPA: 1 }).limit(1)
```

Результат:

```text
Петр — GPA: 3.9
```

После этого документ был удалён:

```javascript
db.students.deleteOne({ name: "Петр" })
```

MongoDB вернул:

```text
acknowledged: true
deletedCount: 1
```

### Результат

Студент с наименьшим средним баллом был успешно найден и удалён из коллекции.

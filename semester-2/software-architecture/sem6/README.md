# Задание

## Требования

1. Установить **Docker Compose**.
2. Разработать приложение на фреймворке **FastAPI** с двумя эндпоинтами:
   - `POST /notes`
   - `GET /notes`

   Запросы должны работать снаружи (с компьютера).

3. Сгенерировать `docker-compose.yaml`, который будет запускать ваше приложение и **PostgreSQL** в двух контейнерах в одной сети.

4. Запустить оба контейнера при помощи:

    ```bash
    docker compose up -d
    ```

5. Продемонстрировать работу системы.

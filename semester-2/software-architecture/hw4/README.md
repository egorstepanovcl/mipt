# Домашнее задание 4. Брокеры сообщений

## Информация о выполнении задания

Задание выполняется **индивидуально**.

## Цель задания

Научиться устанавливать брокер сообщений и организовывать через него взаимодействие микросервисов.

## Условия

В рамках данного задания необходимо установить брокер сообщений Kafka и реализовать через него взаимодействие двух микросервисов.

## Шаги выполнения

1. Установите Kafka на свой компьютер или сервер ([kafka.apache.org — Quickstart](https://kafka.apache.org/quickstart)).
   > Если вы работаете на Windows, можете установить Kafka при помощи Docker.

2. Установите в отдельный контейнер **PostgreSQL**, если вы ещё не делали этого ранее. Если делали — запустите данный контейнер.

3. Создайте **первое приложение** на FastAPI, которое будет принимать запрос на создание записи об ошибке:

    ```
    POST /errors/
    ```

    Тело запроса:
    ```json
    {
        "code": 2043,
        "message": "Everything is broken",
        "details": "Some system details about error"
    }
    ```

    Данное приложение должно класть каждое такое сообщение в Kafka в определённую тему.

4. Создайте **второе приложение** на FastAPI, которое будет получать сообщения об ошибках из Kafka и сохранять их в базу данных PostgreSQL в таблицу `errors` со следующей структурой:

    | Поле | Описание |
    | --- | --- |
    | `id` | Уникальный идентификатор записи |
    | `time` | Время получения сообщения |
    | `code` | Код ошибки |
    | `message` | Сообщение об ошибке |
    | `details` | Детали ошибки |

5. Проверьте работу обоих приложений, используя **Postman**.

## Формат сдачи и отправка задания

**Видеодемонстрация**, на которой должны быть показаны:

- Коды обоих приложений
- Запрос к первому приложению через Postman
- Появление записи в базе данных после отправки запроса

## Сроки выполнения задания

Задание рассчитано на **4 часа**.

## Критерии оценивания

| Критерии | Баллы |
| --- | --- |
| Созданы оба приложения | 2 |
| Первое приложение успешно принимает сообщение в заданном формате и кладёт его в Kafka | 4 |
| Второе приложение получает сообщение из Kafka и кладёт в базу данных, оно появляется в базе данных | 4 |

- **Максимальный балл за задание:** 10 баллов
- **Как проверяется:** в течение недели после дедлайна
